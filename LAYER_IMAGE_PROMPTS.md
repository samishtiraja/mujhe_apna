# Layer image prompts — 63s se gaane ke ant tak

68 poses. Ek drawing poori film mein ek baar. Inhe pehle banao. Timeline baad mein inhi files pe baithegi.

Har image **ek hi figure** hai, sir se pair tak, beech mein, khaali jagah ke saath. Koi paper, koi zameen, koi scene, koi chhaya, koi border, koi likha hua shabd nahi. Radha unmarried hai: maang mein sindoor nahi, sirf chhota bindi, nath, laal odhni. Krishna wahi hai: neela rang, morpankh, bansuri, peetambar.

Generator se square image lo. File ka naam neeche diya hua rakhna, `assets/paper/cast_layers/` mein.

Agar tool transparent PNG nahi de aur peeche ek rang bhar de, to woh rang bilkul plain safed ho, texture ke bina. Prompt yahi maangta hai.
